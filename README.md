# Premier League Data Analytics 2018-2019

Proyecto de análisis estadístico y visualización de datos
de la Premier League inglesa durante la temporada 2018-2019.

## Tecnologías utilizadas

- Python 3.13
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Streamlit

## Objetivos

- Analizar los resultados de los partidos.
- Calcular estadísticas de los equipos.
- Evaluar el rendimiento local y visitante.
- Visualizar estadísticas mediante gráficos.
- Construir un dashboard interactivo.

## Estructura del proyecto

- data: conjuntos de datos.
- src: código fuente.
- notebooks: análisis exploratorios.
- reports: informes y gráficos.
- tests: pruebas automatizadas.
